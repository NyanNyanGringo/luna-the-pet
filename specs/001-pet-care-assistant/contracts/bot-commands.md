# Контракт Telegram-команд

## Команды бота

| Команда | Описание | Приоритет |
|---------|----------|-----------|
| `/start` | Приветствие, регистрация семьи | P1 |
| `/help` | Список команд и подсказки | P1 |
| `/newpet` | Создание нового питомца (диалоговый поток) | P2 |
| `/pets` | Список питомцев с кратким описанием | P2 |
| `/profile [имя]` | Профиль питомца | P2 |
| `/deletepet [имя]` | Удаление питомца (с подтверждением) | P2 |
| `/sos [имя]` | Экстренная карточка | P7 |
| `/vetreport [язык]` | Отчёт для ветеринара | P6 |
| `/dashboard` | Ссылка на веб-панель | P5 |
| `/export` | Экспорт данных JSON | P10 |
| `/import` | Импорт данных из JSON-файла | P10 |
| `/giftideas [имя]` | Список идей подарков | P11 |

## Типы ввода

### Голосовое сообщение

```
Вход: voice message (OGG/Opus)
-> Транскрипция (gpt-4o-mini-transcribe, language="ru")
-> Агент (gpt-4o-mini, function calling)
-> Ответ текстом
```

### Текстовое сообщение (не команда)

```
Вход: text message
-> Агент (gpt-4o-mini, function calling)
-> Ответ текстом
```

### Фотография

```
Вход: photo [+ caption]
-> Классификация типа (passport/document/regular)
-> Если passport: gpt-4o Vision -> structured output -> предложение сохранить
-> Если document: gpt-4o Vision -> извлечение информации -> предложение
-> Если regular: gpt-4o-mini Vision -> описание -> сохранение в галерею
```

## Диалоговые потоки (FSM)

### /newpet

```
Бот: "Как зовут вашего нового питомца?"
Пользователь: "Рекс" (текст или голос)
Бот: "Какой вид животного? (собака, кошка, другое)"
Пользователь: "Собака"
Бот: "Питомец Рекс (собака) создан! Теперь вы можете добавлять информацию о нём."
```

### /deletepet

```
Бот: "Вы уверены, что хотите удалить питомца Рекс? Все данные будут потеряны."
     [Да, удалить] [Отмена]
Пользователь: нажимает кнопку
```

### /vetreport (выбор языка)

```
Если язык указан: сразу генерация
Если есть история языков: инлайн-меню [Русский] [Сербский] [Другой]
Если первый раз: "На каком языке подготовить отчёт?"
```

## Определение питомца в сообщении

Алгоритм:
1. Поиск имени питомца в тексте (точное совпадение, case-insensitive)
2. Если питомец один — используется по умолчанию
3. Если неоднозначно — инлайн-клавиатура: `[Луна] [Рекс]`

## Формат ответов

### Подтверждение записи
```
Записано: вес Луны — 12 кг (2026-03-07)
```

### Карточка /sos
```
SOS: Луна

Аллергии: Аллергия на курицу
Лекарства: Nexgard (1 таблетка, каждые 3 мес.)
Хронические: Не указано
Ветеринар: Клиника Доктор Вет, +7...
Группа крови: Не указано
Бешенство: 2026-01-15
Вес: 12 кг (2026-03-01)
```

### Напоминание
```
Напоминание: пора дать Луне дозу Nexgard!
[Выполнено] [Напомнить завтра]
```

### Контрольное сообщение (через 2 часа)
```
Вы дали Луне Nexgard? Пожалуйста, подтвердите.
[Да, дала] [Нет, ещё нет]
```

## Callback-данные инлайн-кнопок

| Callback | Описание |
|----------|----------|
| `pet_select:{pet_id}` | Выбор питомца для текущего действия |
| `reminder_confirm:{reminder_id}` | Подтверждение выполнения |
| `reminder_snooze:{reminder_id}` | Отложить на завтра |
| `delete_confirm:{pet_id}` | Подтверждение удаления |
| `delete_cancel` | Отмена удаления |
| `vetreport_lang:{code}` | Выбор языка отчёта |
| `vetreport_other` | Другой язык (запрос ввода) |
| `passport_confirm` | Подтверждение данных паспорта |
| `passport_cancel` | Отмена сохранения из паспорта |
