# Контракты: Telegram Bot Commands

**Branch**: `003-group-only-mode` | **Date**: 2026-03-12

## Контекст

Бот взаимодействует с пользователями через Telegram Bot API.
Внешний интерфейс — команды и сообщения в чатах Telegram.

---

## Команды бота

### /start

**Контекст: личный чат (private)**

| Аспект | Значение |
|--------|----------|
| Триггер | Пользователь отправляет `/start` в личный чат |
| Ответ | Приветствие + инструкция по созданию группы |

Формат ответа:
```text
👋 Привет! Я — Луна, ваш помощник по уходу за питомцами.

Я работаю только в групповых чатах. Чтобы начать:

1. Создайте группу в Telegram
2. Добавьте меня в группу
3. Отправьте первое сообщение — и я начну работать!

Так вся семья сможет следить за питомцем вместе 🐾
```

**Контекст: группа (group/supergroup)**

Команда `/start` в группе — не обрабатывается специально (стандартное приветствие при необходимости).

---

### /invite

**Контекст: группа (group/supergroup)**

| Аспект | Значение |
|--------|----------|
| Триггер | Пользователь отправляет `/invite` в группе |
| Успех | Бот отвечает пригласительной ссылкой на группу |
| Ошибка (нет прав) | Бот сообщает о необходимости прав администратора |

Формат ответа (успех):
```text
🔗 Пригласительная ссылка на группу:
https://t.me/+AbCdEfGhIjK

Отправьте эту ссылку тому, кого хотите пригласить.
```

Формат ответа (нет прав):
```text
⚠️ Мне нужны права администратора, чтобы создать ссылку.

Попросите администратора группы назначить меня админом или создайте ссылку вручную через настройки группы.
```

**Контекст: личный чат (private)**

Перенаправление в группу (стандартное поведение для личного чата — см. ниже).

---

### /help

Работает в обоих контекстах. В личном чате — добавляет инструкцию по созданию группы. В группе — стандартная справка.

---

## Поведение в личном чате (любое сообщение)

| Условие | Ответ |
|---------|-------|
| Пользователь не состоит ни в одной группе с ботом | Инструкция по созданию группы (см. `/start`) |
| Пользователь состоит в одной группе | «Я работаю только в группе. Перейдите в группу: {название группы}» |
| Пользователь состоит в нескольких группах | «Я работаю только в группах. Ваши группы:» + список групп |

Это поведение применяется к ЛЮБОМУ типу сообщения: текст, голос, фото, стикеры, команды (кроме `/start` и `/help`).

## События группы

### Бот добавлен в группу

| Аспект | Значение |
|--------|----------|
| Событие | `my_chat_member`: IS_NOT_MEMBER → IS_MEMBER |
| Действие | Создать workspace (или реактивировать) |
| Ответ | Приветственное сообщение в группу |

Формат приветствия:
```text
🐾 Привет! Я — Луна, ваш помощник по уходу за питомцами.

Я умею:
• Вести историю здоровья питомцев
• Напоминать о вакцинациях и лекарствах
• Отвечать на вопросы о уходе

Просто напишите мне что-нибудь о вашем питомце!
Для приглашения новых участников используйте /invite
```

### Бот удалён из группы

| Аспект | Значение |
|--------|----------|
| Событие | `my_chat_member`: IS_MEMBER → IS_NOT_MEMBER |
| Действие | `workspace.is_active = False` |
| Ответ | Нет (бот уже не может отправлять сообщения) |

### Новый участник вступил в группу

| Аспект | Значение |
|--------|----------|
| Событие | `chat_member`: IS_NOT_MEMBER → IS_MEMBER |
| Действие | Создать/реактивировать WorkspaceMember |
| Ответ | Нет (молчаливая регистрация) |

### Участник покинул группу

| Аспект | Значение |
|--------|----------|
| Событие | `chat_member`: IS_MEMBER → IS_NOT_MEMBER |
| Действие | `workspace_member.is_active = False`, `left_at = now()` |
| Ответ | Нет |

### Группа мигрировала в супергруппу

| Аспект | Значение |
|--------|----------|
| Событие | Сообщение с `migrate_to_chat_id` |
| Действие | UPDATE `workspace.telegram_chat_id` с нового ID |
| Ответ | Нет |
