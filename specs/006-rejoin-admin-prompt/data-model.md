# Data Model: 006-rejoin-admin-prompt

## Изменения модели данных

Эта фича **не вводит новых сущностей и не изменяет схему базы данных**.

Вся необходимая информация уже доступна:

- **Различение new/rejoin**: определяется по наличию существующего `Workspace` для `telegram_chat_id` внутри `get_or_create_workspace`. Новый возвращаемый тип `tuple[Workspace, bool]` не требует изменений в БД.
- **Админ-статус бота**: запрашивается в реальном времени через Telegram API (`bot.get_chat_member`). Кэширование не требуется — проверка выполняется только в момент добавления бота в группу (редкое событие).

## Существующие сущности (без изменений)

- **Workspace**: `id`, `telegram_chat_id`, `title`, `is_active` — используется `is_active` для определения реактивации
- **WorkspaceMember**: без изменений
- **WorkspaceSettings**: без изменений

## Миграции

Alembic-миграции **не требуются**.
