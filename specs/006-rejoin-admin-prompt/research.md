# Research: 006-rejoin-admin-prompt

## R-001: Различение нового и реактивированного workspace

**Решение**: `get_or_create_workspace` возвращает `tuple[Workspace, bool]`, где `bool` — флаг `is_new` (True = создан впервые, False = найден/реактивирован).

**Обоснование**: стандартный Django-паттерн `get_or_create -> (obj, created)`, узнаваем Python-разработчикам. Покрывает точную семантику: `is_new=True` → первичное приветствие, `is_new=False` → приветствие возвращения.

**Рассмотренные альтернативы**:
- NamedTuple/dataclass: избыточен для пары (Workspace, bool)
- Проверка `is_active` до вызова: race condition, нарушение инкапсуляции

## R-002: Проверка админ-статуса бота в группе

**Решение**: вызов `bot.get_chat_member(chat_id=chat_id, user_id=bot.id)` и проверка `status in ("administrator", "creator")`.

**Обоснование**:
- `bot.id` — синхронное свойство, извлекает ID из токена без API-вызова
- `event.new_chat_member.status` при добавлении бота = `"member"` (не `"administrator"`), поэтому из события нельзя определить admin-статус
- Исключение: если бот добавлен через настройки группы сразу как админ, `new_chat_member` будет `ChatMemberAdministrator` — но этот случай покрывается дополнительной проверкой через `get_chat_member`

**Рассмотренные альтернативы**:
- Полагаться на `event.new_chat_member.status`: ненадёжно — при обычном добавлении статус всегда `"member"`
- Использовать `isinstance(member, ADMINS)`: эквивалентно, но менее явно для чтения

## R-003: Тексты приветственных сообщений

**Решение**: три варианта приветствия в `constants.py`:

1. **Первичное приветствие** (`GROUP_WELCOME_TEXT`): текущий текст + строка о назначении админом
2. **Приветствие возвращения без прав** (`GROUP_REJOIN_TEXT`): компактное тёплое сообщение с просьбой об админ-правах
3. **Приветствие возвращения с правами** (`GROUP_REJOIN_ADMIN_TEXT`): компактное тёплое сообщение без просьбы о правах

**Обоснование**: три отдельных константы проще тестировать и читать, чем шаблон с условными подстановками. Соответствует текущему паттерну в `constants.py`.
