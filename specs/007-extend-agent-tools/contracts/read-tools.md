# Контракты инструментов чтения

**Feature**: 007-extend-agent-tools
**Date**: 2026-03-17

## Инструменты чтения для существующих данных

### get_weight_history

Возвращает историю веса питомца.

**Параметры**:

| Параметр | Тип | Обязательный | Описание |
| -------- | --- | ------------ | -------- |
| pet_name | string | да | Имя питомца |
| limit | integer | нет | Количество записей (default: 10) |

**Возврат**: текстовое представление записей (дата, вес в кг), сортировка по дате DESC.

**Пример ответа**:
```
История веса Луны (последние 3 записи):
• 15.03.2026 — 28.5 кг
• 01.03.2026 — 28.2 кг
• 15.02.2026 — 27.8 кг
```

### get_vaccinations

Возвращает все вакцинации питомца.

**Параметры**:

| Параметр | Тип | Обязательный | Описание |
| -------- | --- | ------------ | -------- |
| pet_name | string | да | Имя питомца |

**Возврат**: текстовое представление всех вакцинаций (название, дата, следующая дата, ветеринар, серия, заметки).

---

### get_medications

Возвращает лекарства питомца.

**Параметры**:

| Параметр | Тип | Обязательный | Описание |
| -------- | --- | ------------ | -------- |
| pet_name | string | да | Имя питомца |
| active_only | boolean | нет | Только активные (default: false) |

**Возврат**: текстовое представление лекарств, разделённых на активные и завершённые (если active_only=false).

### get_feeding_history

Возвращает историю кормлений за период.

**Параметры**:

| Параметр | Тип | Обязательный | Описание |
| -------- | --- | ------------ | -------- |
| pet_name | string | да | Имя питомца |
| start_date | string (YYYY-MM-DD) | нет | Начальная дата периода |
| end_date | string (YYYY-MM-DD) | нет | Конечная дата периода |

**Возврат**: текстовое представление кормлений (дата/время, описание, порция), сортировка по времени DESC. Без параметров — последние 7 дней.

---

### get_current_diet

Возвращает текущую диету питомца.

**Параметры**:

| Параметр | Тип | Обязательный | Описание |
| -------- | --- | ------------ | -------- |
| pet_name | string | да | Имя питомца |

**Возврат**: текстовое представление текущей активной диеты (бренд, тип корма, дата начала, заметки). Если нет активной диеты — сообщение «Текущая диета не задана».

---
